# Q: How does the Cloudia WhatsApp button support multi-location branch chats?

## Answer

An optional Branch selector setting accepts one entry per line as Branch name | WhatsApp number. When enabled with valid entries, the floating button opens a minimal inline location shelf; choosing a location tracks and opens that branch WhatsApp chat. The original single number remains the fallback when the selector is disabled.
