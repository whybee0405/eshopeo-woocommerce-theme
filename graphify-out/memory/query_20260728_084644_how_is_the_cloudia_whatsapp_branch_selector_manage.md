# Q: How is the Cloudia WhatsApp branch selector managed and presented after the frontend polish?

## Answer

Cloudia settings now provide repeatable branch name and WhatsApp-number rows with Add branch and Remove controls. Existing legacy textarea entries remain readable as a fallback. The frontend uses a green circular icon trigger with a support callout, and its scrollable branch shelf is explicitly hidden until the icon is activated.
